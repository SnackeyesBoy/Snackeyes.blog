# 眼動智慧量測系統

### 專案簡介
此計劃為研究所實驗室與國立臺灣大學醫學院附設醫院雲林斗六分院的跨學界合作計劃。主要負責眼動智慧量測系統開發與實驗規劃，使用 Ganzin 眼動儀追蹤瞳孔變化與運動軌跡變化，並運用 C# 結合專屬 SDK 設計實驗操作 UI 介面，供醫院臨床研究進行精確資料蒐集。

### 工具與技術
* **硬體設備**：Ganzin Sol Glass
* **開發語言**：C#
* **開發環境**：Visual Studio Code
* **核心技術**：Ganzin SDK 整合、即時眼動數據追蹤與 UI 互動設計

### 設備清單

| 設備名稱 | 數量 |
| :--- | :---: |
| **Ganzin Sol Glass** | 1 |
| **LapTop** | 1 |
| **USB-A to Type-C** | 1 |

### 介面介紹
1. **瞳孔大小變化操作介面**：監測並即時記錄受測者瞳孔縮放幅度與時間序列變化。

2. **瞳孔運動變化操作介面**：捕捉眼球轉向軌跡、注視點分佈及凝視持續時間。
